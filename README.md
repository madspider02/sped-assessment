# 特殊教育鑑定資料整合系統 v5.0

系統研發者：國家教育研究院黃彥融副研究員

GitHub 網址：https://madspider02.github.io/sped-assessment/

這是舊版 v4 的小幅改版，仍維持 **GitHub Pages → Google Apps Script → Google Sheets → 瀏覽器 PDF**，不使用 Firebase。

## 這次修改的四個重點

1. **智能障礙學生組自動顯示**：一般學生組的前四向度至少一項符合 `標準分數 <= 72` 或 `百分等級 PR <= 3`，而且第五向度「學科（領域）學習表現」也符合其中任一條件，就立即顯示智能障礙學生組 12 個分量表的輸入欄位、五向度平均與折線圖。未符合則不顯示。**沒有手動開啟勾選框，也不需填理由。** 若標準分數或百分等級其中一個尚未填入，只要另一個已符合門檻仍可先自動顯示；最終送出之前，一般學生組五向度的兩類資料仍須填完整。
2. 左側第四個步驟名稱由「社會適應」改成「適應行為」；評量工具正式名稱仍保留「社會適應表現檢核表（第二版）」。
3. 第 07 步驟刪掉冗長的後台儲存說明，只留下教師初步研判、確認與送出結果。
4. **移除通行碼欄位與後端通行碼驗證**。填表時不再要求輸入通行碼，也不需在 Apps Script 設定 `SUBMISSION_KEY`。

## 升級步驟：原本的 Google Sheet 不需要重建

### A. 更新 Apps Script（務必先做）

1. 進入你原本執行過 `setupSheets()` 的 **同一個 Apps Script 專案**。
2. 先備份舊的 `Code.gs`，再用本版本的 `Code.gs` 完整取代。
3. 在最前面的 `SPREADSHEET_ID` 設定為你**原來使用的 Google Sheet ID**，不要保留 `PASTE_SPREADSHEET_ID`。
4. 按**儲存**。
5. 點選「**部署 → 管理部署作業 → 編輯（鉛筆）**」，在**版本**選擇「**新增版本**」，再按「**部署**」。請更新**原本的網頁應用程式部署**，以便保留相同的 `/exec` 網址。

原本的七個工作表資料與欄位可以繼續使用；不用重新執行 `setupSheets()`。為相容舊資料，`Adaptive_ID` 分頁仍保留兩個歷史欄位 `manual_override` 和 `override_reason`，但新版會自動填入 `false` 和空白，不再提供人工開啟功能。

**注意：如果只修改 GitHub，沒有更新並重新部署 `Code.gs`，舊後端仍會要求通行碼而導致送出失敗。**

### B. 更新 GitHub

1. 到 https://github.com/madspider02/sped-assessment 的儲存庫根目錄。
2. 上傳本版的 **`index.html`**（i 小寫）及 **`assessment-pdf.js`**，取代同名舊檔。
3. 點選 **Commit changes**，等待 GitHub Pages 重新發布。
4. 開啟 https://madspider02.github.io/sped-assessment/ ，若還顯示舊內容，使用無痕視窗或重新載入。

此版 `index.html` **已填入你提供的 Apps Script `/exec` 網址**，不需要再次貼網址；如果日後另建 Apps Script 部署，才需修改 `SHEETS_WEB_APP_URL`。

### C. 用虛構個案驗收

1. 第 04 步驟選「已完成評量」，輸入填寫者、日期及五向度一般學生組分數。
2. 範例一：第 1 向度標準分數 `72`、第五向度 PR `3`，應自動展開智能障礙學生組（其餘向度維持一般分數）。
3. 範例二：第 1 向度標準分數 `73`、PR `4`，其他前三向度均高於門檻，第五向度 PR `3`，**不可**展開，因前四向度沒有一項達條件。
4. 依完整流程按「確認資料並形成PDF」，確認 Sheets 七分頁有同一個 `case_id`，收到成功回覆後才開始下載 PDF。

## 隱私與權限提醒

這版移除通行碼後，若 Apps Script 網頁應用程式設為「**任何人**」、執行身分設為「**我**」，**任何取得公開 `/exec` 網址的人都可能向你的私人 Sheet 提交資料**。Google Sheets 不公開瀏覽不等於寫入端點受到保護。本版不提供逐一驗證教師身分、拒絕未授權提交或避免惡意灌入的可靠機制。

因此，上線驗收階段**只使用虛構或不含可識別個資的測試個案**；若要正式蒐集學生姓名、出生日期及心理測驗結果，需先採用機構核可的存取保護方式，不宜將這個「免通行碼、任何人可提交」的版本當成封閉系統。
